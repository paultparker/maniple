Design Notes

Defensive reading: The coordinator dict is read via .get() on every key, so an unexpected shape (future schema bump, partial capture) never raises. Matches the fail-open philosophy of CoordinatorIdentity itself.
Minimal render logic: Only fields that are known are included in the section. The section is omitted entirely when no identity is present at all.
Backward compatibility: Existing callers that don't pass coordinator=... get the default None and see no section. No breaking changes.
